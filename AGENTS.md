
# Project Instructions

## Project
This repository contains an AI-powered web application.

## Sources of Truth
- Read `docs/PRD.md` for product requirements.
- Read `docs/ARCHITECTURE.md` for system boundaries.
- Read `docs/DESIGN.md` for UI-related tasks.
- Use `docs/PLAN.md` for implementation milestones.
- Use `docs/TASKS.md` to track verified progress.
- Do not read every document for every trivial change.

## Development Workflow
- Inspect relevant existing code before editing.
- For non-trivial features, propose a plan before implementation.
- Implement one coherent task at a time.
- Prefer minimal, focused changes.
- Do not add dependencies without justification.
- Do not change unrelated functionality.

## Verification
- Run relevant tests, linting, and type checking.
- Never claim a test passed unless it was actually run.
- Update TASKS.md only after verifying completion.
- Report any remaining issues.

## Safety
- Never commit secrets or credentials.
- Do not modify production data.
- Ask before destructive or irreversible operations.

## Final Response
Summarize:
1. What changed
2. Files modified
3. Verification results
4. Known limitations
